## Why this matters

`constitucionesNic` is an R **data-only** package: it ships four datasets and
contains no R functions. Its `DESCRIPTION` nevertheless lists four packages
under `Imports:` (`htm2txt`, `here`, `dplyr`, `purrr`). Those packages are used
only by the data-building script `data-raw/DATASET.R`, which is excluded from
the built package. Because they are declared as `Imports`:

1. `R CMD check` **fails with an ERROR** on any machine that does not have
   them installed: `Packages required but not available: 'htm2txt', 'here'`.
2. Every user running `remotes::install_github("RRMaximiliano/constitucionesNic")`
   is forced to install four unnecessary packages (plus their dependency trees).

Removing the `Imports:` field was tested on a clean copy of this commit:
`R CMD check` then reports `Status: OK` with zero warnings and zero notes.
This plan is the prerequisite for CI (plan 002): CI cannot go green while
check errors.

The plan also adds `^plans$` to `.Rbuildignore`. This `plans/` directory of
handoff documents lives at the repo root, and without the entry `R CMD check`
reports `NOTE: Non-standard file/directory found at top level: 'plans'`, so it
would never reach a clean `Status: OK`.

## Commands you will need

Run all commands from the package root (the directory containing `DESCRIPTION`).

| Purpose | Command | Expected on success |
|---------|---------|---------------------|
| Build + check (writes only to a temp dir) | `P=$PWD; T=$(mktemp -d) && (cd "$T" && R CMD build "$P" && _R_CHECK_FUTURE_FILE_TIMESTAMPS_=FALSE R CMD check --no-manual constitucionesNic_*.tar.gz)` | Last lines include `Status: OK` |
| Tests only | `Rscript -e 'testthat::test_local()'` | `[ FAIL 0 | WARN 0 | SKIP 0 | PASS 4 ]` (or similar with FAIL 0) |

The command builds and checks inside a fresh temp directory, so no build
artifacts land in the repo. Do not append anything after it (e.g. `; echo`):
its exit status must be the check's exit status.

`grep -c` prints a count; when the expected count is `0`, grep also exits with status 1. That is normal. Judge by the printed number, not the exit status.

## Steps

### Step 1: Confirm the imports are unused

Run:

```sh
grep -rnE 'htm2txt|here::|dplyr|purrr|library\(|require\(' R/ tests/ NAMESPACE
```

**Verify**: the only matches are `library(testthat)` and
`library(constitucionesNic)` in `tests/testthat.R`, and
`library(constitucionesNic)` in `tests/testthat/test-data.R`. If anything
under `R/` or `NAMESPACE` matches, STOP.

### Step 2: Delete the `Imports:` field from `DESCRIPTION`

Remove exactly these five lines (the field name plus its four continuation lines):

```
Imports: 
    htm2txt,
    here,
    dplyr,
    purrr
```

Leave every other line untouched, including the trailing space after
`Depends: ` (it is harmless and already present). Keep LF line endings. Do not
introduce CRLF.

**Verify**:
- `grep -c '^Imports' DESCRIPTION` → `0`
- `Rscript -e 'd <- read.dcf("DESCRIPTION"); stopifnot(!"Imports" %in% colnames(d), d[,"Package"] == "constitucionesNic"); cat("ok\n")'` → prints `ok`
- `file DESCRIPTION` → must NOT mention `CRLF`

### Step 3: Exclude `plans/` from the package build

Append this line at the end of `.Rbuildignore` (keep the existing six lines unchanged):

```
^plans$
```

**Verify**: `tail -1 .Rbuildignore` prints `^plans$`, and `wc -l < .Rbuildignore` prints `7`.

### Step 4: Run the full check

Run the "Build + check" command from the table above.

**Verify**: output ends with `Status: OK`. (The command sets
`_R_CHECK_FUTURE_FILE_TIMESTAMPS_=FALSE`, which skips a check that needs
network access and would otherwise add a spurious NOTE offline.) Any ERROR,
WARNING or NOTE is a STOP condition. A NOTE mentioning `plans` means
`.Rbuildignore` is wrong. A `plans` NOTE can only appear if `plans/` exists in
your checkout; if it doesn't, the `tail -1 .Rbuildignore` check in Step 3 is
the only proof.

### Step 5: Run the tests

`Rscript -e 'testthat::test_local()'`

**Verify**: `FAIL 0`.
