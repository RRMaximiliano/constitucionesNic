## Why this matters

`constitucionesNic` ships four datasets: `cons_1974`, `cons_1987`,
`cons_2010` and `cons_2014`. Each has one row per line of a Nicaraguan
constitution, plus columns that place the line in the document's structure.
Users analyse the text through those structural columns (e.g.
`count(tema)`). Several of them are wrong today:

1. **Values leak across titles.** `cap` (chapter) and `art` (article) are
   carried down across the whole document, so a new title's heading rows
   inherit the previous title's chapter and article. Example: `cons_1974`
   line 30 is the heading `TÍTULO II` but has `cap = "CAPÍTULO II"` and
   `art = "15"`, both belonging to Título I.
2. **`tema` (topic) is wrong for almost all of 1974.** The old rule takes
   "the second row of each title". In the 1974 layout (`TÍTULO` → `CAPÍTULO`
   → topic) that row is the chapter heading. So `tema` is `"CAPÍTULO I"`,
   `"CAPÍTULO ÚNICO"`, … The body has only 7 distinct values across 17 titles.
   In 2014, Título V has a two-line topic and only the first line is kept.
3. **Labels aren't normalized.** 1974 types the Roman numeral I as a lowercase
   L (`"TÍTULO Vlll"`, `"TÍTULO lX"`, `"CAPÍTULO l"`), and accents vary inside
   one dataset (`"CAPITULO ÚNICO"` and `"CAPITULO UNICO"` in 1987;
   `"TITULO III"` next to `"TÍTULO IV"` in 2010). `group_by(titulo)` and
   `group_by(cap)` therefore split groups that should be one.
4. **The closing text is mis-attributed.** Promulgation formulas, the list of
   signatories and, in 2010/2014, the reform history after the last article
   are labelled as part of the last article and title. In `cons_1987`, 59 rows
   of signatures count as Article 202.
5. **Heading rows are mixed with body text**, and nothing marks them. A word
   count by topic includes the headings.

This plan replaces the parsing section of `data-raw/DATASET.R` with a
heading-aware parser, regenerates the data, and documents the result as
version 0.2.0. The `text` and `line` columns stay **identical**; only the
structural columns change. The advisor built and validated this exact end
state on a scratch copy: data regenerated, 170 test expectations passing, and
`R CMD check` → `Status: OK`.

How the source text is laid out (verified in all four snapshots). Each
constitution body is a sequence of blocks:

```
TÍTULO <roman>                        e.g. "TÍTULO II", "TITULO IV", "TÍTULO Vlll"
[0–2 title-topic lines]               e.g. "SOBRE EL ESTADO"; 2014 Título V has two lines
CAPÍTULO <roman | ÚNICO>              e.g. "CAPITULO UNICO", "CAPÍTULO ll"
[0–1 chapter-name line]               e.g. "DERECHOS INDIVIDUALES"; absent after most 1987+ "CAPÍTULO ÚNICO"
Arto. <n>… / Artículo <n>…            article text, continuing over following lines
```

- 1974 layout: `TÍTULO` → (topic line only for some titles, e.g. Título V
  "Derechos y Garantías") → `CAPÍTULO` → chapter name (always present).
  Títulos I and IX have several chapters and no title topic.
- 1987 / 2010 / 2014 layout: `TÍTULO` → topic line(s) → `CAPÍTULO` → chapter
  name only when the chapter is numbered (not `ÚNICO`).
- Article starts: `Arto. 1.- …` (1974, 1987), `Arto. 1 …` (2010),
  `Artículo 1. …` (2014).
- Rows before the first `TÍTULO` line form the preamble (5 / 24 / 25 / 28 rows).
- The closing section starts at the first line after the last article
  that begins with `Dado en` / `Dada en` / `DADO EN`. Examples: 1974 `Dada en
  el Salón de Sesiones…`, 1987 `DADO EN LA SALA DE SESIONES…`, 2010/2014 `Dado
  en la Sala de Sesiones…`.

```r
# Parsing ------------------------------------------------------------------
#
# Each snapshot line becomes one row. Structure of every constitution body:
#
#   TÍTULO <n>                      <- title heading            (tipo "encabezado")
#   [0-2 title-topic lines]         <- become `tema`            (tipo "encabezado")
#   CAPÍTULO <n | ÚNICO>            <- chapter heading          (tipo "encabezado")
#   [0-1 chapter-name line]         <- becomes `cap_tema`       (tipo "encabezado")
#   Arto. <n> ... / Artículo <n>... <- article text, continues until next heading
#
# Rows before the first TÍTULO are the preamble ("preambulo"). Rows from the
# first line starting with "Dado/Dada en" after the last article onward are the
# closing formalities (promulgation, signatures, reform history) ("cierre").

re_titulo <- "^T[ÍI]TULO\\s+[IVXl]+$"
re_cap    <- "^CAP[ÍI]TULO\\s+([IVXl]+|[ÚU]NICO)$"
re_art    <- "^(Artículo|Arto\\.)\\s*([0-9]+)"
re_cierre <- "^(Dad[oa]|DAD[OA])\\s"

# "TITULO Vlll" -> "TÍTULO VIII"; "CAPITULO UNICO" -> "CAPÍTULO ÚNICO".
# The source sometimes types a lowercase L instead of the Roman numeral I.
normalize_label <- function(x) {
  word <- str_extract(x, "^\\S+")
  num  <- str_trim(str_remove(x, "^\\S+"))
  word <- recode(word, "TITULO" = "TÍTULO", "CAPITULO" = "CAPÍTULO")
  num  <- if_else(num %in% c("UNICO", "ÚNICO"), "ÚNICO", str_replace_all(num, "l", "I"))
  if_else(is.na(x), NA_character_, paste(word, num))
}

parse_constitution <- function(lines, year) {
  d <- tibble(year = as.integer(year), line = seq_along(lines), text = lines) %>%
    filter(text != ".") %>%
    mutate(
      is_titulo = str_detect(text, re_titulo),
      is_cap    = str_detect(text, re_cap),
      art_start = as.integer(str_match(text, re_art)[, 3])
    )

  first_titulo <- which(d$is_titulo)[1]
  last_art     <- max(which(!is.na(d$art_start)))
  cierre_rows  <- which(seq_len(nrow(d)) > last_art & str_detect(d$text, re_cierre))
  if (is.na(first_titulo)) stop("No TÍTULO heading found for ", year)
  if (length(cierre_rows) == 0) stop("No closing 'Dado en' line found for ", year)
  first_cierre <- cierre_rows[1]

  d <- d %>%
    mutate(
      idx = row_number(),
      seccion = case_when(
        idx < first_titulo  ~ "preambulo",
        idx >= first_cierre ~ "cierre",
        TRUE                ~ "cuerpo"
      ),
      en_cuerpo  = seccion == "cuerpo",
      titulo_raw = if_else(is_titulo & en_cuerpo, text, NA_character_),
      cap_raw    = if_else(is_cap & en_cuerpo, text, NA_character_)
    )

  # Title: carried down from its heading, only inside the body.
  d <- d %>%
    fill(titulo_raw) %>%
    mutate(titulo_raw = if_else(en_cuerpo, titulo_raw, NA_character_))

  # Chapter: carried down only within its own title, so a new title's
  # heading rows never inherit the previous title's chapter.
  d <- d %>%
    group_by(titulo_raw) %>%
    fill(cap_raw) %>%
    ungroup() %>%
    mutate(cap_raw = if_else(en_cuerpo, cap_raw, NA_character_))

  # Heading rows: the TÍTULO line, title-topic lines (between TÍTULO and the
  # first CAPÍTULO), the CAPÍTULO line, and the chapter-name line (the line
  # right after CAPÍTULO when it is not an article).
  d <- d %>%
    group_by(titulo_raw) %>%
    mutate(tema_line = en_cuerpo & cumsum(is_cap) == 0 & !is_titulo) %>%
    group_by(titulo_raw, cap_raw) %>%
    mutate(cap_tema_line = en_cuerpo & !is.na(cap_raw) & first(is_cap) &
             row_number() == 2 & is.na(art_start)) %>%
    ungroup() %>%
    mutate(tipo = if_else(en_cuerpo & (is_titulo | is_cap | tema_line | cap_tema_line),
                          "encabezado", "texto"))

  # Article: carried down only within its own chapter, never onto headings.
  d <- d %>%
    group_by(titulo_raw, cap_raw) %>%
    fill(art_start) %>%
    ungroup() %>%
    mutate(art = if_else(en_cuerpo & tipo == "texto", art_start, NA_integer_))

  # Topics. `tema` = the title-topic lines joined by a space. If a title has
  # no topic lines but exactly one chapter, the chapter name is the title's
  # topic (1974 layout). Otherwise `tema` is NA.
  temas <- d %>%
    filter(tema_line) %>%
    group_by(titulo_raw) %>%
    summarise(tema_titulo = paste(text, collapse = " "), .groups = "drop")
  cap_temas <- d %>%
    filter(cap_tema_line) %>%
    select(titulo_raw, cap_raw, cap_tema = text)
  n_caps <- d %>%
    filter(is_cap, en_cuerpo) %>%
    count(titulo_raw, name = "n_caps")

  d %>%
    left_join(temas, by = "titulo_raw") %>%
    left_join(cap_temas, by = c("titulo_raw", "cap_raw")) %>%
    left_join(n_caps, by = "titulo_raw") %>%
    group_by(titulo_raw) %>%
    mutate(tema_unico_cap = if (isTRUE(first(n_caps) == 1)) first(na.omit(cap_tema)) else NA_character_) %>%
    ungroup() %>%
    mutate(
      tema = case_when(
        seccion == "preambulo" ~ "PREÁMBULO",
        seccion == "cierre"    ~ NA_character_,
        !is.na(tema_titulo)    ~ tema_titulo,
        TRUE                   ~ tema_unico_cap
      ),
      titulo = if_else(seccion == "preambulo", "PREÁMBULO", normalize_label(titulo_raw)),
      cap    = normalize_label(cap_raw)
    ) %>%
    select(year, line, text, titulo, cap, art, tema, cap_tema, seccion, tipo)
}

df <- years %>%
  map(~ parse_constitution(cons_df$text[cons_df$year == .x], .x)) %>%
  bind_rows()
```
